# sample-sites

クラウドワークス応募用の提案サンプルサイトを案件単位で管理するリポジトリです。

## 公開対象
Cloudflare Pages では、案件ごとに `projects/<案件ID>` を `Root directory` に指定して公開します。

今回の公開対象:
- `projects/20260320_basketball_association`

- 提案用サンプルのため、一部にダミー表現を含みます
