# 20260427_sales_support_qr_agent_mock

## このサンプルサイトの目的
- クラウドワークス応募時に提示するための提案用サンプルサイトです。
- 代理店・エージェントによるQRコード営業、紹介店舗管理、注文管理、売上・報酬管理の全体像を静的モックで伝えることを目的としています。
- 本番アプリではなく、要件理解、画面設計、仕様整理の支援ができることを示すための制作物です。

## 案件概要との対応
- 管理者、エージェント、店舗の3者構造をページ内で整理しています。
- エージェント固有ID付きQRコードから店舗登録へ進む流れを図解しています。
- 店舗登録時にエージェントIDを固定し、注文売上と報酬見込みへつながる構造を表現しています。
- 管理者画面、エージェントマイページ、店舗向け注文画面のUIイメージを配置しています。
- Google Places API連携予定はカード表示のみで、実際の外部API通信は行っていません。

## 公開ファイル配置
- 公開用ファイルは `sample-site/sales-support-qr-agent-mock/` に配置しています。
- Cloudflare Pages の Root directory は既存運用どおり `sample-site` を想定しています。
- 想定公開URL: `/sales-support-qr-agent-mock/`

## ページ構成
- `sample-site/sales-support-qr-agent-mock/index.html`
  - アプリ全体像、3者構造、QR営業フロー、注文・報酬発生の概要
- `sample-site/sales-support-qr-agent-mock/screens.html`
  - 管理者、エージェント、店舗の画面モック一覧
- `sample-site/sales-support-qr-agent-mock/flow.html`
  - エージェント登録から月次報酬確定までのステップ説明

## 実装している内容
- 静的HTML / CSS / JavaScriptによる提案用モック
- レスポンシブ対応
- タブ切り替えによる画面モック表示
- ダミーQR、KPIカード、テーブル、ステータスバッジ、簡易グラフ風UI
- 提案用サンプルであることの注記

## 実装していない内容
- 本物のログイン機能
- 本物のQRコード生成
- 本物の注文処理
- 本物の報酬計算処理
- Google Places API連携
- Firebase、Node.js、DB接続などのバックエンド実装
- 個人情報入力や送信処理

## 公開時の注意点
- 提案用サンプルモックであり、本番アプリとして誤認されないように説明文とフッター注記を残しています。
- 掲載している店舗名、エージェント名、金額、報酬率、注文状況はすべてサンプルです。
- 本番化する場合は、認証、権限、ID固定仕様、注文フロー、報酬確定処理、API利用条件を別途要件定義する必要があります。
