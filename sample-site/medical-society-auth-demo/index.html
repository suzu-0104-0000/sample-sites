Implementation View

対応イメージ / 想定機能

営業資料のように重くしすぎず、案件理解が自然に伝わるようカードで整理しています。

01

外部認証API連携を想定

ログイン画面から外部認証基盤へ接続し、結果に応じて会員向け導線へ遷移する設計をイメージしています。

02

会員専用ページの閲覧制御

/member/ 配下に保護ページを集約し、未ログイン時はログイン画面へ戻す構成を想定しています。

03

セッション管理の導線設計

ログイン後の状態保持、会員名表示、ログアウト導線までを見える形で配置し、会員制サイトらしい操作感を出しています。

04

WordPress組み込み想定

テンプレート化しやすい情報ブロックで構成し、ログイン画面HTML支給やテーマ組み込みのイメージを持ちやすくしています。

Flow Design

会員導線の想定フロー

  1. 公開トップで学会概要と会員導線を提示 一般公開情報と会員向け情報を整理し、ログイン導線をファーストビュー内で案内します。
  2. ログイン画面で認証の入り口を明確化 メールアドレスまたは会員番号で認証するUIを提示し、外部API連携を前提とした雰囲気を表現します。
  3. 認証後は会員専用ページへ遷移 会員向けお知らせや限定資料を一覧で見せ、保護されたページであることを視覚的に伝えます。
  4. ログアウトで未認証状態へ戻す セッション管理を想起できる自然な導線として、会員ページ上部にログアウトを配置しています。

Member Access

ログイン画面から擬似ログインし、会員専用ページまでの遷移と閲覧制御の雰囲気を確認できます。
